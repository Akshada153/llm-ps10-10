# Headline & Title Generator (PS10)

**Name:** Akshada Patil | **Roll No:** 10 | **Class:** LYCORE1

## Problem statement
Writers often struggle to come up with catchy titles. This app takes an article
or topic and uses an LLM (Gemini 3.5 Flash-Lite) to generate 10 headline options,
each rated 1-10 for clarity, shown in a table sorted from clearest to least clear.

## How to run
1. Get a free API key from https://aistudio.google.com/apikey
2. Copy `.env.example` to `.env` and paste your key
3. Install and run:
```
pip install -r requirements.txt
streamlit run app.py
```
